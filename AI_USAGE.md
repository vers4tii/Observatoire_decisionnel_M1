# Déclaration d'usage de l'IA générative

L'usage d'IA générative est autorisé s'il est déclaré et vérifié. Aucune donnée confidentielle ni aucun secret (clé, mot de passe, donnée personnelle) n'est transmis à un service d'IA. Chaque membre doit pouvoir expliquer tout code ou texte produit avec une IA.
