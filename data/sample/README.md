# Échantillon d'exemple

`exemple_communes.csv` contient des **valeurs fictives**, construites pour exercer le pipeline et les tests sans réseau. Les codes ont un format INSEE réaliste mais les noms, populations et indicateurs sont inventés : ne les citez jamais comme des résultats.

Pièges volontairement présents :

- un code commune sans zéro initial (`1001` au lieu de `01001`) ;
- un code corse (`2A004`) et un code d'outre-mer (`97411`) ;
- des nombres au format français (espace des milliers, virgule décimale) ;
- une valeur manquante ;
- une ligne en double.

Remplacez ou complétez cet échantillon par un extrait réduit de vos vraies données dès le jalon J2.
